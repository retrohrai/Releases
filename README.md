# RetroHrai! — The Modern Android Launcher for Retro Gaming

A beautiful, unified frontend launcher for Android that brings all your games together in one place. Play games from multiple emulators - retro classics, modern platforms, and everything in between - without juggling between different apps.

## ✨ Features

### Your Games, All in One Place
- **Unified Game Library** - Access games from all your emulators in a single, beautiful interface
- **Automatic Platform Detection** - Setup wizard scans your folders and organizes everything automatically
- **Custom Platforms** - Create your own platforms using any Android app as the emulator, with custom file extensions and launch methods
- **Multiple View Modes** - Switch between Carousel, List, and Grid views, with per-platform memory
- **Collections** - Build custom game collections across platforms, choose your Favorites or visit your Recently Played
- **Multi-Disc Support** - M3U playlist support with individual disc files automatically hidden

### Visual Experience
- **Dynamic Backgrounds** - Game screenshots and fanart come alive as backgrounds while you browse
- **Game Card Overlays** - Style your cover arts like physical cartridges with customizable overlays support
- **3D Card Animations** - Optional 3D tilt effects on active game cards
- **Custom Fonts** - Choose your own font for the entire launcher UI
- **Wallpaper Engine Support** - Use system wallpapers or connect Wallpaper Engine for live backgrounds

### Dual-Screen Excellence
- **Widget Board** - Display built-in widgets like Now Playing and System Stats on your secondary screen, or use widgets from any other Android app
- **Per-Platform Display Preference** - Remember which screen each platform uses, with per-game override
- **Independent Wallpapers** - Set separate wallpapers for each display
- **Screen Mirror Widget** - Mirror your primary screen with zoom and trackpad modes
- **Virtual Second Screen** - Dual-screen experience even on single-screen devices

### Metadata & Scraping
- **Four Scraping Providers** - IGDB, TheGamesDB, ScreenScraper, and SteamGridDB
- **Background Scraping** - Scrape your entire library without interrupting your browsing
- **Manual Metadata Editing** - Edit titles, descriptions, genres, and release dates how you want
- **Media Migration Wizard** - Import existing media from other frontends

### Platform & Emulator Support
- **Wide Emulator Compatibility** - Works with popular emulators across retro and modern platforms
- **Per-Game Emulator Override** - Choose a different emulator for any individual game
- **Windows Games** - Launch PC/Steam games via Winlator, GameNative and GameHub shortcuts

### Controls & Audio
- **Hardware Button Mapping** - Bind physical buttons to control brightness, volume, and launcher actions
- **Browsing Music** - Play background music while navigating your library
- **Per-Game Background Music** - Set individual background tracks for any game
- **Backup & Restore** - Export and restore your full launcher setup, so your configuration is never lost

## 🚀 Installation

1. Download the latest APK from the [Releases](https://github.com/retrohrai/Releases/releases) page
2. Enable "Install from Unknown Sources" in your Android settings if prompted
3. Install the APK and launch RetroHrai! — the setup wizard will guide you through adding your game folders and scanning your platforms

Alternatively, RetroHrai! is also available on [Google Play](https://play.google.com/store/apps/details?id=com.retrohrai.launcher) if you prefer to install and update it from there.

## 📱 Compatibility

- **Android Version:** Android 8.0 or higher
- **Tested Devices:** Primarily tested on Retroid Pocket 5 and AYN Thor, compatible with various Android handhelds and phones
- **Screen Support:** Single screen, dual screen, portrait and landscape modes
